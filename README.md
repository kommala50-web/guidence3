# TechPath – Skill Roadmap Platform

TechPath is a frontend web application that provides structured learning roadmaps for different technology domains. It helps beginners understand what to learn and in what order.

## Live Demo
https://vijaybunny-project.netlify.app

## Features
- Beginner-friendly skill roadmaps
- Clean and responsive user interface
- Simple navigation for learning paths

## Tech Stack
- HTML5
- CSS3
- JavaScript

Personal Project
